# Personal AI Workspace & Knowledge Sync Client

Google Cloud OAuth 동의 화면(Consent Screen)에 연동된 개인용 OAuth 클라이언트의 홈페이지 및 개인정보처리방침 호스팅 저장소입니다.

- **홈페이지**: [https://hmacoder.github.io/rclone-oauth/](https://hmacoder.github.io/rclone-oauth/)
- **개인정보처리방침**: [https://hmacoder.github.io/rclone-oauth/privacy.html](https://hmacoder.github.io/rclone-oauth/privacy.html)

이 클라이언트는 소유자 본인의 AI 에이전트(Antigravity, Obsidian MCP) 개발 환경에서 프로젝트 지식 베이스를 안전하게 동기화하기 위한 비공개 개인 클라이언트입니다.
